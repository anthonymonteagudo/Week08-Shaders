Optional reference routes

Use the gallery menu’s bracketed reference IDs: route B = reference 08, C = 11, D = 10. These IDs match the slides; the wall numbers indicate the new teaching order.

A · Master-material diagnostic (only if needed)

Open the separate master-material area (reference 14) in W09_MaterialGallery. Duplicate MI_W09_05_PolishedMetal in /Game/Week09/NotesMaster/Instances and assign your duplicate to one test mesh. Keep UsePackedORM off. Set both MinRoughness and MaxRoughness to 0.2 for A, then both to 0.8 for B. Equal endpoints remove texture variation, so one conceptual variable changes: constant roughness. Record both parameter fields. Keep metallic, tint and normal strength fixed. Expect broader reflections at 0.8; record what you actually observe.

Reset: restore both recorded baseline values or reassign the original instance. The supplied polished-metal instance starts at 0.12 for both fields.

B · Painted height transition

At station 08, duplicate MI_08_HeightBlend and assign it to the height-blend sphere. Record Blend Contrast (the staged value is 2), then compare 1 and 4 while keeping vertex paint, textures and tiling fixed. Inspect the transition boundary and silhouette. The height function shapes the transition; it does not displace this mesh.

Reset: restore the recorded contrast and original assignment. Optional after this test: inspect Mesh Paint channels without changing the saved paint. Ordinary blend uses R=stone/G=sand; the height blend uses R as its blend control.

C · Shared and per-object controls

At station 11, record MPC_11_SharedControls.SharedRoughness (staged default 0.28). Compare 0.2 and 0.8: all three referencing spheres should change. Restore it. Then change only one mesh component’s Custom Primitive Data RGB entries 0–2. That component should change color. These are two sequential tests, with a reset between them.

Reset: restore the collection value and each edited data entry. Duplicating a material instance does not isolate a collection parameter. Work in your own project copy.

D · Decal surface response

At station 10, select the roughness decal actor. Duplicate its MI_10_RoughnessDecal material and assign it in the decal actor’s material slot. Compare Roughness 0.03 and 0.8 while keeping projection, receiver, lighting and view fixed. Judge reflected light, not a new base-color patch.

Reset: restore the original decal assignment and recorded value. If it is invisible, inspect projection bounds/direction, the receiver’s Receives Decals setting and material Decal Response before adding more complexity.

Optional extension · Parallax depth

Use this after completing your chosen core route. Budget about four minutes for the first comparison; quality and distance tests are further study.

  1. Pilot 07 BRICK WORKSHOP CAMERA. Inspect the assigned POM instance, duplicate it, assign your copy, and record the original values.
  2. Keep the same mesh, light, tiling and close camera view. Compare POM | Near Height: 0.00 → 0.04. Keep Far Height and step settings fixed.
  3. Move sideways to inspect apparent depth, then check the outer silhouette. Capture A/B from the same view. Explain why the silhouette remains unchanged.
  4. Restore your recorded overrides and original assignment. Verify the reset.

Further study: test step count separately at a shallow angle. The staged near/far height values are both .04: height does not fade out in this configuration. On your copy, test Far Height 0 as a separate distance experiment. Keep steps at least 1 and far distance greater than near distance.

Record: control and scope, fixed conditions, before/after values, visible benefit, one failure case, evidence and reset. Test the result in environmental lighting too.

Pixel Depth Offset can affect depth intersections; it does not create mesh geometry. Keep it fixed during your first comparison.

Station 25: ShaderToy → HLSL → Unreal

Star Nest uses one Image pass with no texture channels or feedback buffers. Its source is MIT-licensed. The gallery adaptation is in /Game/Week09/AdvancedStudies/M_StarNest_Port.

  1. Inspect the license, inputs and pass dependencies before porting.
  2. Supply normalized UV, Time, aspect ratio and exposed rotation parameters. Match vertical UV direction.
  3. Translate vec3 → float3, mix → lerp and fract → frac. GLSL mod uses x-y*floor(x/y); HLSL fmod differs for negative values. Verify matrix multiplication order.
  4. Return float3 from the Custom node to Emissive in an Unlit material. Unreal exposure and tonemapping affect the displayed result.
  5. Compare the 8-step and 20-step instances with UseFrozenTime=1 and FreezeTime=10. Change one control, then restore animation with UseFrozenTime=0. Profile on the target machine; more steps are not automatically worth the cost.

Ideas for an existing shader

Outside examples, not bundled source projects. The small exercises below are suggested extensions.

  • Lava: drive a controlled emissive pulse with a crack mask.
  • Aurora: animate noise and a color gradient on one ribbon.
  • Film / VHS: add one controllable screen-space distortion.
  • Vines: reveal or recolor a decal through a coverage mask.
