Color and tint

First set Tint to white: the untinted texture. Then reduce the red channel. Which source colors change, and why?

Native graph

TextureCoordinate → Texture Sample UVs. Texture Sample RGB × Vector Parameter Tint → Emissive Color. Surface / Opaque / Unlit. Tint (1,1,1) preserves the source RGB.

Named inputs

  • UV (float2)
  • BaseTexture (TextureObject, sRGB color)
  • Tint (float3, linear multiplier)

GLSL calculation

// Original classroom calculation. Host supplies inputs; GLSL runs in the browser.
vec3 base = texture(BaseTexture, UV).rgb;
vec3 color = base * Tint;

Unreal Custom-node HLSL

// UE Custom node body. Output Type: Float3. See README for inputs.
float3 base = Texture2DSample(BaseTexture, BaseTextureSampler, UV).rgb;
float3 color = base * Tint;
return color;
