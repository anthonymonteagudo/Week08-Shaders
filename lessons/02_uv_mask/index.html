UVs and masks

Move the transition edges. Explain why this is a mask rather than a color texture.

Native graph

TextureCoordinate → ComponentMask R → SmoothStep (Min .25, Max .75) → Lerp Alpha. ShadowColor → A; Tint → B; result → Emissive Color.

Named inputs

  • UV (float2)
  • Tint (float3)
  • ShadowColor (float3)

GLSL calculation

// Original classroom calculation. Host supplies inputs; GLSL runs in the browser.
float mask = smoothstep(0.25, 0.75, UV.x);
vec3 color = mix(ShadowColor, Tint, mask);
