Palette and brush texture

Set TextureInfluence to zero, then .18. Change the palette without changing the band boundaries.

Native graph

Brush sample R × 2 − 1 → Multiply influence → Add to light response → Saturate. Two Step nodes select three colors through two Lerps. The full UE playground adds a fourth color and editable thresholds.

Named inputs

  • N (float3, world)
  • L (float3, world)
  • UV (float2)
  • Tiling (float)
  • TextureInfluence (float)
  • BrushTexture (TextureObject)
  • ShadowColor (float3)
  • MidColor (float3)
  • Tint (float3)

GLSL calculation

// Original classroom calculation. Host supplies inputs; GLSL runs in the browser.
float light = clamp(dot(normalize(N), normalize(L)), 0.0, 1.0);
float brush = texture(BrushTexture, UV * Tiling).r;
light = clamp(light + (brush * 2.0 - 1.0) * TextureInfluence, 0.0, 1.0);
vec3 color = mix(ShadowColor, MidColor, step(0.35, light));
color = mix(color, Tint, step(0.7, light));

Unreal Custom-node HLSL

// UE Custom node body. Output Type: Float3. See README for inputs.
float light = saturate(dot(normalize(N), normalize(L)));
float brush = Texture2DSample(BrushTexture, BrushTextureSampler, UV * Tiling).r;
light = saturate(light + (brush * 2.0 - 1.0) * TextureInfluence);
float3 color = lerp(ShadowColor, MidColor, step(0.35, light));
return lerp(color, Tint, step(0.7, light));
