Texture and motion

Set Speed to zero. Then double Tiling. Does the mesh move?

Native graph

TexCoord × Tiling → Add time offset → Texture Sample UVs. Use R → Lerp Alpha. In a Custom node use a TextureObject named BrushTexture; UE supplies BrushTextureSampler.

Named inputs

  • UV (float2)
  • Tiling (float)
  • Seconds (float)
  • Speed (float)
  • BrushTexture (TextureObject)
  • Tint (float3)
  • ShadowColor (float3)

GLSL calculation

// Original classroom calculation. Host supplies inputs; GLSL runs in the browser.
vec2 flowUV = UV * Tiling + vec2(Seconds * Speed, 0.0);
float mask = texture(BrushTexture, flowUV).r;
vec3 color = mix(ShadowColor, Tint, mask);

Unreal Custom-node HLSL

// UE Custom node body. Output Type: Float3. See README for inputs.
float2 flowUV = UV * Tiling + float2(Seconds * Speed, 0.0);
float mask = Texture2DSample(BrushTexture, BrushTextureSampler, flowUV).r;
return lerp(ShadowColor, Tint, mask);
