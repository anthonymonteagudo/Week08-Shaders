View mask and dark edge

Try a pale edge, then dark purple. Why can a Lerp darken the edge while adding a positive color cannot?

Native graph

PixelNormalWS · CameraVectorWS → Saturate → OneMinus → Power → Multiply EdgeStrength → Lerp Alpha. UE Fresnel with BaseReflectFraction 0 is a related native shortcut.

Named inputs

  • N (float3, world)
  • V (float3, world, toward camera)
  • RimPower (float)
  • EdgeStrength (float)
  • Tint (float3)
  • EdgeColor (float3)

GLSL calculation

// Original classroom calculation. Host supplies inputs; GLSL runs in the browser.
float edge = pow(1.0 - clamp(dot(normalize(N), normalize(V)), 0.0, 1.0), RimPower);
vec3 color = mix(Tint, EdgeColor, edge * EdgeStrength);

Unreal Custom-node HLSL

// UE Custom node body. Output Type: Float3. See README for inputs.
float edge = pow(1.0 - saturate(dot(normalize(N), normalize(V))), RimPower);
return lerp(Tint, EdgeColor, edge * EdgeStrength);
