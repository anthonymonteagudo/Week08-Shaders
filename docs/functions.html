Common material functions
GLSL → HLSL → Unreal nodes

Small building blocks, explicit inputs, and one experiment each. These are calculation excerpts, not complete shaders. Names in code are example variables; Unreal nodes need the corresponding connections. Read the input range and coordinate space before copying a formula.

Reading order: Multiply → Lerp → masks → UVs → lighting → motion. Derivatives and normal transforms are optional references.

Color and values

Multiply / Add

Tint a sampled color; scale or offset a value.

GLSL

vec3 color = tex.rgb * tint;
float y = x * scale + bias;

HLSL

float3 color = tex.rgb * Tint;
float y = x * Scale + Bias;

Unreal nodes

Multiply: A × B
Add: A + B

Check: Multiplication is component-wise. A scalar scales every component. Multiplying by white preserves RGB; by black removes it.

Try: Set tint to (1, 0.5, 0.5). Which channels remain unchanged?

Color and values

Mix / Lerp

Use a mask to blend between two colors.

GLSL

vec3 c = mix(a, b, mask);

HLSL

float3 c = lerp(A, B, Mask);

Unreal nodes

LinearInterpolate (Lerp)
A, B, Alpha = mask

Check: Alpha 0 returns A; 1 returns B. Values outside 0..1 extrapolate. A color Alpha blends channels independently.

Try: Set Alpha to 0, .5 and 1 before connecting a texture.

Color and values

Clamp / Saturate

Keep a response within an intended range.

GLSL

float y = clamp(x, 0.0, 1.0);

HLSL

float y = saturate(X);

Unreal nodes

Saturate: clamp to 0..1
Clamp: explicit Min / Max

Check: Clamping is not normalization or remapping: values outside the range collapse to the endpoints.

Try: Preview -0.5, 0.4 and 1.5 through Saturate.

Coordinates and textures

Remap a signed field

Convert a stored 0..1 channel into a signed UV offset.

GLSL

vec2 flow = data.gb * 2.0 - 1.0;

HLSL

float2 flow = Data.gb * 2.0 - 1.0;

Unreal nodes

ComponentMask GB → Multiply 2
→ Subtract 1

Check: A sampled .5 becomes zero offset. Import data textures with sRGB OFF.

Try: Connect signed flow to UVs with a small strength such as .02.

Masks and bands

Step

Build a sharp binary mask or lighting threshold.

GLSL

float mask = step(edge, x);

HLSL

float mask = step(Edge, X);

Unreal nodes

Step: X = value
Y = edge

Check: Result is 0 when x < edge and 1 otherwise. UE Step uses X for the value and Y for the edge; the code arguments put the edge first.

Try: Raise the edge and watch the bright region shrink.

Masks and bands

Smoothstep

Turn a hard edge into a smooth transition.

GLSL

float mask = smoothstep(lo, hi, x);

HLSL

float mask = smoothstep(Lo, Hi, X);

Unreal nodes

SmoothStep: Min, Max, Value

Check: Keep Min < Max. This softens a value transition; it does not blur a texture or guarantee anti-aliasing.

Try: Increase Max − Min while keeping their midpoint fixed.

Coordinates and textures

Fract / Frac

Repeat a ramp or make repeating procedural UV patterns.

GLSL

float ramp = fract(x);

HLSL

float ramp = frac(X);

Unreal nodes

Frac

Check: Result is x − floor(x), also for negative x. Explicit Frac creates derivative discontinuities; texture wrapping usually handles repeating UVs better.

Try: Compare fract(-.2) with fract(.8). Both are .8.

Coordinates and textures

Time + UV offset

Scroll texture coordinates without moving geometry.

GLSL

vec2 uv2 = uv * tiles + seconds * speed;

HLSL

float2 uv2 = UV * Tiles + Seconds * Speed;

Unreal nodes

TextureCoordinate × Tiles
→ Add(Time × speed), or Panner

Check: UV speed is repeats per second. Use a float2/vector with two meaningful channels. Mesh positions do not change.

Try: Reverse only speed.x. Predict the motion direction.

Coordinates and textures

Sample a texture

Read color or packed numeric channels at a UV.

GLSL

vec4 data = texture(tex, uv);

HLSL

float4 data = Texture2DSample(Tex, TexSampler, UV);

Unreal nodes

Texture Sample: UVs input
RGB / R / G / B / A outputs

Check: The HLSL example is UE Custom-node syntax with a TextureObject input named Tex. Raw HLSL instead uses Texture2D.Sample with a SamplerState. GLSL syntax shown is GLSL ES 3.00 / modern GLSL; older WebGL 1 uses texture2D. Color data and numeric masks need different sRGB import choices.

Try: Preview R, G, B and A individually before using a packed texture.

Coordinates and textures

Components / Append

Extract channels or assemble a vector.

GLSL

vec2 flow = data.gb;
vec3 n = vec3(slope, 1.0);

HLSL

float2 flow = Data.gb;
float3 n = float3(Slope, 1.0);

Unreal nodes

ComponentMask G+B
AppendVector: float2 + scalar

Check: RGBA and XYZW name the same component positions. Appending does not normalize a direction.

Try: Preview only the green channel; then append two scalar controls.

Light response

Normalize + Dot

Measure alignment between directions for diffuse light or masks.

GLSL

float light = clamp(dot(normalize(N), normalize(L)), 0.0, 1.0);

HLSL

float light = saturate(dot(normalize(N), normalize(L)));

Unreal nodes

Normalize N + Normalize L
→ DotProduct → Saturate

Check: Use nonzero vectors in the same space. L points toward the light. Dot of unit vectors ranges from -1 to 1 before clamping.

Try: Rotate L while holding N fixed. When does the response become zero?

Light response

Power + view rim

Make a controllable highlight near grazing view angles.

GLSL

float rim = pow(1.0-clamp(dot(N,V),0.0,1.0), power);

HLSL

float rim = pow(1.0-saturate(dot(N,V)), Power);

Unreal nodes

Dot(N,V) → Saturate → OneMinus
→ Power (Base, Exp)

Check: Normalize N and V first. Higher positive power narrows the rim. This artistic mask alone is not a complete Fresnel reflectance model. UE Fresnel adds its own BaseReflectFractionIn parameter and expects a world-space normal.

Try: Compare Power 1, 3 and 6 using the same camera.

Masks and bands

Floor + bands

Reduce a smooth light value to a chosen number of levels.

GLSL

float q = min(floor(x*n),n-1.0)/(n-1.0);

HLSL

float q = min(floor(X*N),N-1.0)/(N-1.0);

Unreal nodes

Multiply → Floor → Min(n−1)
→ Divide(n−1)

Check: x is clamped 0..1 and n is an integer ≥2. The Min keeps x=1 at the final level rather than making an extra band.

Try: Compare 2, 4 and 6 levels; keep the light still.

Motion and geometry

Sine / Cosine

Create periodic motion for pulses or waves.

GLSL

float y = sin(phaseRadians);

HLSL

float y = sin(PhaseRadians);

Unreal nodes

Sine: set Period to 6.283185
for a radian input

Check: Code sin/cos use radians. UE Sine/Cosine default Period is 1: an input of 1 completes a cycle. Alternatively divide radians by 2π and keep Period 1.

Try: For 1 cycle per second, use sin(seconds × 2π) in code, or Time → Sine with Period 1 in UE.

Masks and bands

Length / Distance

Build radial masks or control distance-based effects.

GLSL

float d = length(uv - center);

HLSL

float d = length(UV - Center);

Unreal nodes

Subtract → Length
(or Distance between two vectors)

Check: UV distance is not world distance. On a stretched surface a UV circle may appear stretched.

Try: Use 1 − smoothstep(radius−softness, radius, d) for a soft disk.

Motion and geometry

Vertex displacement

Change the visible surface shape, such as wave height.

GLSL

position.z += height; // vertex stage

HLSL

return float3(0,0,HeightCm); // WPO input

Unreal nodes

World Position Offset
expects a world-space offset

Check: The GLSL example assumes a local +Z plane. UE WPO uses world units (normally cm), needs enough vertices, and does not automatically update collision. Vertex displacement also needs matching shading normals.

Try: Set height to 0, then 6 cm. Inspect the silhouette, not just highlights.

Advanced reference

DDX / DDY / Fwidth

Estimate how a pixel-stage value changes across nearby fragments.

GLSL

float width = fwidth(x);
vec3 nx = dFdx(N);

HLSL

float width = fwidth(X);
float3 nx = ddx(N);

Unreal nodes

DDX / DDY
Abs(DDX) + Abs(DDY) for fwidth

Check: These are screen derivatives, not an analytic object-space slope. Use in the pixel stage. Discontinuous control flow or values can make them unreliable.

Try: Optional: use fwidth to scale a procedural edge transition as the camera moves.

Advanced reference

Normal-space transform

Compare directions in the same space.

GLSL

vec3 Nworld = normalize(TBN * Ntangent);

HLSL

float3 Nworld = normalize(mul(TBN, Ntangent));

Unreal nodes

TransformVector: Tangent → World
then Normalize

Check: The matrix examples define TBN with tangent, bitangent and normal as columns. UE handles the mesh basis through TransformVector. Packed slopes are not a ready-to-use normal-map texture; build and normalize the vector first.

Try: Toggle a world-normal debug color. A rotating object should rotate its world normal.

Blend colors with a view-angle falloff and a face-on value.

GLSL

float edge = pow(1.0-clamp(dot(N,V),0.0,1.0), exponent);
float mask = mix(base, 1.0, edge);

HLSL

float edge = pow(1.0-saturate(dot(N,V)), Exponent);

Unreal nodes

Utility Fresnel
ExponentIn, BaseReflectFractionIn
Normal: world-space

Check: Calculation excerpt assumes unit N and V in world space. This mask alone does not implement a full physical BRDF.

Try: Open MI_06_FresnelTight in the Epic reference room. Compare Exponent 1 and 5.

DepthFade concept

Soften the intersection of a translucent surface and opaque geometry.

GLSL

// Conceptual: both depths must be linear
float fade = clamp((sceneDepth-pixelDepth)/distance,0.0,1.0);
float alpha = opacity * fade;

HLSL

// Conceptual: engine depth input required
float fade = saturate((SceneDepth-PixelDepth)/Distance);
float alpha = Opacity * fade;

Unreal nodes

DepthFade: Opacity, FadeDistance
Output to material Opacity
Blend Mode: Translucent

Check: These are conceptual excerpts, not ready-to-paste depth-buffer reads. Keep distance positive and depth units consistent. Use the engine node for the actual study.

Try: Compare FadeMix 0 and 1 around the opaque rock. The plane geometry should stay fixed.

World-space texture projection

Choose repeat size in world units instead of mesh UV scale.

GLSL

// One XY projection only
vec2 uv = worldPos.xy / size.xy;
vec3 c = texture(tex, uv).rgb;

HLSL

// One XY projection only
float2 uv = WorldPos.xy / Size.xy;
float3 c = Texture2DSample(Tex, TexSampler, uv).rgb;

Unreal nodes

WorldAlignedTexture function
TextureObject + TextureSize
XYZ Texture blends three projections

Check: The code shows one projection, not Epic's complete triplanar implementation. Use nonzero Size. World coordinates remain fixed as a mesh moves.

Try: Move the World coordinates cube, then Undo. Double-click WorldAlignedTexture to inspect the complete function.
