Why the UE snippet is not a drop-in preview

The course’s unreal-custom.hlsl is a Custom-node body. Unreal supplies named inputs, output type and helpers such as Texture2DSample. A standalone preview needs a supported entry point, vertex/fragment interface, resources and host bindings. The arithmetic stays the same while the wrapper changes.

Shared arithmetic: sampledRGB * Tint
Browser: GLSL texture(), uniforms and fragment output
Unreal: Custom inputs, Texture2DSample(), return float3
Preview: entry point + texture/sampler/resource bindings

Classroom recommendation

Use existing browser GLSL experiments, read matched HLSL, then inspect Unreal nodes. This protects the opening and avoids a new runtime prerequisite. A later optional pilot could start with a solid color, then one uniform, then a texture before porting the tint. Test student Windows/Mac setups, diagnostics and output parity before assigning it.
