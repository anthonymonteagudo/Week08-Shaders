Rendering and inputs

A renderer forms an image from a scene and camera. The basic rasterization route is vertices → triangle coverage → fragment shading → image; engines use multiple passes. A material defines surface behavior; an instance overrides exposed parent parameters.

UVs address textures. Local coordinates belong to an object; world coordinates share a frame. Normalize nonzero directions and put both vectors in the same space before a dot product. For unit vectors, dot is 1 when aligned, 0 perpendicular, −1 opposite. Reversing cross-product order reverses its nonzero result.

Unreal outputs and settings

The code pairs use Surface / Opaque / Unlit → Emissive Color. A Default Lit material instead supplies surface inputs such as Base Color and Roughness for scene lighting. Color RGB normally uses sRGB decoding; numerical mask RGB uses linear data. Alpha is not sRGB-decoded.

Opaque does not use Opacity for ordinary coverage. Masked uses Opacity Mask and a clip threshold; Translucent uses Opacity to blend. A color Lerp and Two Sided do not enable transparency. The supplied mask graph expands smoothstep into clamped cubic arithmetic.

Water

Simple: moving texture samples on fixed geometry. Intermediate: texture-driven vertex height. Advanced: Gerstner vertical and horizontal displacement. Height and Gerstner can change silhouettes; displacement needs enough vertices and suitable normals. Complexity is not a quality ranking. Lab 1 gives exact instances and controls.

Lighting, color, and stylization

A key light defines form; fill changes shadow visibility. A real rim light illuminates an edge from behind or beside the subject. A view-angle mask uses camera direction instead. Roughness changes the spread of reflections; hold camera, lights, exposure, and color fixed when comparing it.

Hue identifies a color family, saturation its intensity, and value its light/dark level. In the Wind Waker reference, study broad value regions, crisp boundaries, and chosen shadow colors. The lesson’s dot → threshold → color blend is an experiment inspired by those visible features, not Nintendo’s implementation.
