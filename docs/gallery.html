Reading the graph

Follow the numbered comment sections from named inputs to the output. Parameter defaults establish a starting point; the MI exposes selected choices. Graphs are calculations: left-to-right placement is an explanation aid, not CPU execution order.

The lighting study uses an explicit light-direction parameter for its Unlit examples. Actual scene lights affect the Default Lit bay. A Fresnel-style view mask is different from a back light.
