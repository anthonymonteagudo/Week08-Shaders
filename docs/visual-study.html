Week 8 · Visual study route

Use a visual, make a prediction, then explain the result.

Start with the class guide. These optional visual references help when a concept is hard to picture. Each opens the author’s original work; software wrappers and defaults may differ from our UE 5.7 and browser examples.

A short review route

  1. Direction and light: explain the role of a surface normal before thresholding.
  2. Shape and shading: distinguish moving vertices from updating normals.
  3. Texture sampling: explain why a distant pattern changes with filtering.

Then choose a topic tied to your experiment: flow maps, threshold edges, color interpretation, transparent edges or palette ramps. None adds a new submission requirement.

Equal numeric steps are not equal steps of light

Bartosz Ciechanowski · Color Spaces · Slide 16 · color/data review

Open the source and visual

sRGB transfer curve

Try / predict: Compare a midpoint chosen in encoded values with a linear-light blend. Predict whether a data mask should undergo the same interpretation as a color texture.

Check your explanation

A mask stores a numeric control. A color texture’s encoding needs the appropriate conversion before lighting calculations; avoid applying that conversion twice.

Explain without the visual

  1. Which input changes when you pan UVs? Does that require a moving silhouette?
  2. What does a normal map change, and what does it leave alone?
  3. Why can filtering a texture help even when the mesh has plenty of vertices?
  4. How could the same scalar mask control color in one material and roughness in another?
  5. Why might a calculation produce a different result before interpolation than after it?
Check the central ideas

UV panning changes lookup addresses. A normal map changes shading directions. Filtering addresses the texture’s sample footprint. A mask can choose between different kinds of numeric outputs. Nonlinear operations, such as thresholding or normalization, generally do not commute with interpolation.
