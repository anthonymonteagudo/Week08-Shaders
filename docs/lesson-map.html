Each calculation below comes from the actual student file. GLSL runs in the browser; HLSL is the corresponding Unreal Custom-node calculation. The host supplies inputs and the output wrapper.

01_color

Slide 11: Tint in GLSL, Slide 12: The same tint in Unreal HLSL

GLSL

vec3 base = texture(BaseTexture, UV).rgb;
vec3 color = base * Tint;

HLSL

float3 base = Texture2DSample(BaseTexture, BaseTextureSampler, UV).rgb;
float3 color = base * Tint;
return color;

06_painted_bands

Slide 64: Brush texture perturbs the light signal, Slide 65: The complete painted-band study

GLSL

float light = clamp(dot(normalize(N), normalize(L)), 0.0, 1.0);
float brush = texture(BrushTexture, UV * Tiling).r;
light = clamp(light + (brush * 2.0 - 1.0) * TextureInfluence, 0.0, 1.0);
vec3 color = mix(ShadowColor, MidColor, step(0.35, light));
color = mix(color, Tint, step(0.7, light));

HLSL

float light = saturate(dot(normalize(N), normalize(L)));
float brush = Texture2DSample(BrushTexture, BrushTextureSampler, UV * Tiling).r;
light = saturate(light + (brush * 2.0 - 1.0) * TextureInfluence);
float3 color = lerp(ShadowColor, MidColor, step(0.35, light));
return lerp(color, Tint, step(0.7, light));
